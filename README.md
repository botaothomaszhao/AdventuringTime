# 探索的时光 Adventuring Time

纯本地的足迹地图应用，用于记录一个人的一生轨迹：在哪里生活（长期地点）、去过哪里（行程与地点）、走过什么路（路径）、人生如何展开（时间线与轨迹线）。所有数据保存在本机，格式开放（GPX + 扩展字段），不依赖任何云服务。

## 功能总览

- **地图**：瓦片地图（可切换瓦片源）、地址搜索、图层开关、点击地图落点
- **深色模式**：安卓跟随系统（深色下瓦片自动反色适配）；桌面保持浅色
- **长期地点**：人生轨迹节点（出生地/家/学校/公司），必填到达时间，支持年/月/日精度
- **行程**：一段旅行，包含路径、地点、封面、起终点长期地点引用
- **路径**：GPS 轨迹（安卓实时记录）或手绘路径，支持顶点编辑、整体平移
- **人生轨迹线**：长期地点与行程按时间排序相连成人生线
- **时间线**：长期地点与行程按时间混合排序展示
- **统计**：记录/推算里程、长期地点数、行程数、照片数
- **局域网同步**：Windows 端作服务器，多设备双向合并
- **备份**：每次写入前自动备份（内容无变化时跳过）；人物整包导出/导入（.atrip）

## 一键安装

正式安装包发布在 GitHub **Release** 页：[https://github.com/botaothomaszhao/AdventuringTime/releases](https://github.com/botaothomaszhao/AdventuringTime/releases)

- **Android**：下载最新版本的 `.apk` 安装包，传到手机后手动安装（首次需允许「安装未知应用」；签名变化时需先卸载旧版）。
- **Windows**：下载最新版本的 `setup` 安装包（`.exe`），双击运行按向导完成安装，桌面/开始菜单会出现应用图标。

各版本信息与变更记录见 Release 说明。

## 使用说明

### 1. 首次启动：创建人物

应用为「一人一档」设计，每个人物独立保存全部数据。

1. 打开应用，点击左上角「选择人物」下拉 →「新增人物」，输入姓名（可选简介）。
2. 新建后自动进入该人物。可随时切换/新增/编辑/删除人物：
   - **切换**：点左上角标题下拉，点其他人物
   - **编辑/删除**：下拉菜单中「编辑资料」「删除当前人物」（删除会连同备份物理删除，谨慎操作）
   - **导出/导入**：下拉菜单「导出人物整包 (.atrip)」打包该人物全部数据到下载目录；「导入人物整包」可从文件选择 .atrip 还原。导入时若该人物已存在，可选择「合并」（保留两端数据，冲突以较新为准）或「覆盖」。

### 2. 地图主界面

底部三个标签：**地图 / 时间线 / 统计**。地图页是核心。

- **图层开关**：右上角图层按钮，可独立开关 地点 / 长期地点 / 路径 / 人生轨迹线 的显示
- **缩放**：右下角 +/- 按钮，或双指捏合
- **地址搜索**：顶部搜索框，输入地名（Photon 地理编码，中文支持），结果以数字标注在地图上，点标注选点
- **点击命中**：点地图上的路径/连接线可打开对应卡片；点空白处关闭
- **添加模式**：左下角有「添加地点」「绘制路径」「新建行程」三个按钮，进入对应模式后顶部会显示操作提示横幅

### 3. 添加与编辑地点

- **普通地点**：点「添加地点」→ 在地图上点落点 → 弹窗填名称（可自动反向地理编码）、说明、时间、附图，并**必须**选择所属行程。
- **长期地点**：同样落点后在弹窗中切换为「作为长期地点」。长期地点是人生轨迹节点（家/学校/工作地等），必填到达时间（支持年/月/日精度），不归属任何行程，出现在时间线与轨迹线中。
- **移入/移出**：点已保存的地点卡片 →「移入行程」/「移出行程」，把长期地点归属到某段行程里（旅行中常住地等场景）。
- **编辑/删除**：点地点卡片对应按钮；长期地点也可在时间线页直接点卡片编辑。

### 4. 行程

- **新建**：点「新建行程」→ 填名称、说明、起止日期，可选起点/终点长期地点（作为行程在轨迹线上的锚点）、封面图。
- **详情**：点地图上的行程连接线或时间线/统计里的行程卡片进入详情页：说明内联编辑、统计摘要、按日期分组的地点与路径列表（组内可按天上移/下移手动调序，点条目可回到地图并聚焦）、照片墙。
- **在行程中添加地点/路径**：地图上进入添加模式后，弹窗内行程下拉可选中该行程。

### 5. 路径

- **手绘路径**：点「绘制路径」→ 在地图上逐点点击落点（误点可点「退出」撤销）→ 点「完成」→ 选所属行程 → 填名称/说明/时间/附图。手绘路径的时间用于轨迹线排序。
- **GPS 轨迹**：见第 6 节「实时记录」。保存后的轨迹是 GPS 轨迹（trk，各点带时间），与手绘路径在卡片上区分显示。
- **编辑**：点路径卡片 →「编辑信息」改名称/说明/附图；「整体平移」拖动路径到新位置；「删除路径」移除。
- **顶点编辑**：编辑模式下手绘路径可拖动顶点、点击顶点删除、点击相邻两点之间插入新顶点。

### 6. 实时轨迹记录（Android）

需要定位权限。地图页左上角红色圆钮开始记录，前台服务持续采样落盘，即使切后台/杀进程也不丢失。

- **开始**：点左上角圆钮 → 请求定位权限 → 开始记录，右上角出现信息条（状态/时长/里程/当前速度）
- **暂停/继续**：信息条上的暂停按钮
- **停止并保存**：再点左上角圆钮 → 弹出保存对话框，选/新建所属行程、填轨迹名与说明 → 保存为该行程一条 GPS 轨迹
- **蓝点**：实时位置蓝点。空闲时走系统定位流；记录会话期间（记录/暂停）改用前台服务实时推送的位置，不随采样/暂停跳变；添加地点模式下点蓝点可在当前位置直接添加地点
- **右下角回位按钮**：回到当前位置，方向复位正北
- **恢复**：如果记录中途应用被系统杀掉，重进应用会自动恢复会话并继续记录
- **速度统计**：记录中实时显示当前速度；保存为 GPS 轨迹后卡片展示长度、平均与最高速度（暂停/无信号产生的超长间隔段不计入瞬时速度）

### 7. 时间线与统计

- **时间线**：长期地点与行程按时间混合排序。长期地点卡片可直接点编辑，右上角菜单可移入/移出行程、删除；行程卡片可编辑、删除，点击进入详情。
- **统计**：每人总览（记录里程/推算里程/长期地点/行程/照片）+ 各行程统计，点行程卡片进入详情。

### 8. 设置

右上角设置按钮进入：

- **地图瓦片源**：推荐 Carto Voyager（墙内可用）；备选 Esri、OpenStreetMap（需墙外）。自定义模板须为 WGS-84 Web Mercator。切换后「保存瓦片源」即时生效；瓦片有磁盘缓存，「清除瓦片缓存」可强制刷新。
- **地址搜索服务**：Photon（默认，墙内可用）或 Nominatim（OSM 官方，墙内可能超时）。
- **局域网同步**：见第 9 节。
- **数据目录**：显示当前数据根目录，可修改（留空恢复默认），修改后重启应用生效。

### 9. 局域网同步

用于把数据在 Windows 与手机/多台电脑间同步，双向并集合并，冲突以较新版本为准，被覆盖版本自动进备份。

1. **Windows 端**：设置 → 局域网同步 →「启动服务器」（默认端口 8024），记下显示的本机 IP（如 192.168.1.5）。
2. **其他设备（手机/另一台电脑）**：设置 → 局域网同步 → 输入服务器地址 `IP:8024` →「立即同步」。完成后提示拉取/推送/删除的数量。
3. 两端改任意一端数据后再同步，即可互相合并。同一局域网内可配防火墙放行该端口。

### 10. 备份与数据位置

- **数据根目录**：`%USERPROFILE%\AdventuringTime\data`（Windows），见设置页「数据目录」。
- **自动备份**：每次写盘前自动备份到 `backups/`，删除行程/人物前也会备份；内容与最近一次备份完全一致时自动跳过，不产生重复备份。备份对话框的「手动备份」始终生成新备份。可从备份目录手工恢复。
- **导出整包**：人物下拉 →「导出人物整包 (.atrip)」可带走全部数据，在另一台设备上导入即可。
- **备份与恢复**：直接拷贝 `data/people/` 整个目录即可整体备份/迁移。

## 数据存储

默认数据根目录：`%USERPROFILE%\AdventuringTime\data`

```
data/people/<personId>/
├── profile.json        # 个人信息
├── life.gpx            # 长期地点（人生轨迹节点）
├── media/              # 图片池（mediaId 引用）
├── trips/<tripId>/
│   ├── trip.json       # 行程元数据（名称/说明/日期/起终点/封面）
│   └── trip.gpx        # 行程内容（wpt 地点 + trk/rte 路径）
└── backups/            # 每次写入前的自动备份
```

GPX 扩展：`isEvent`（长期地点，atrip:eventType=life）、`timePrecision`（年/月/日）、起终点引用、行程内手动调序 `orderIds` 等写入 GPX 扩展字段。所有写入先备份再落盘。

## 技术栈

- Flutter（Windows 桌面 + Android），Riverpod 状态管理
- flutter_map 8.x + Carto Voyager 瓦片（默认，墙内可用，WGS-84 无偏移）；Esri / OSM 可在设置切换
- 地址搜索/反向地理编码：Photon（https://photon.komoot.io/）
- 数据存储：GPX 文件 + JSON 元数据（见上文）
- 局域网同步：Windows 内置 HTTP 服务（端口 8024）
